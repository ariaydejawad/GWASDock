# GCTA GWAS Analysis Example

This folder contains scripts and instructions to perform GWAS analysis using FastLMM within a Docker environment, as part of the GWASDock toolkit.

## Contents

- `input/`  
  - This folder contains only the phenotype file `phenotype.txt`.  

  - Following the instructions in the main [README.md](../README.md) to download the phenotype file (`GSTP011.pheno`). Convert it to the GCTA-compatible format using:  

    ```bash
    (echo -e "FID\tIID\tTSLL"; awk 'BEGIN{OFS="\t"} NR>1{print $1, $1, $2}' GSTP011.pheno) > phenotype.txt
    ```
  - **Note:** The genotype files are not included in this repository. Download these files as instructed in the main [README.md](../README.md).
- `output/`  
  - The directory stores the results of GCTA GWAS analysis, generated by `run_gcta.py`.
## Usage

### Step 1: Setup Environment and Launch Container
Navigate to the directory containing the `setup_gcta_gwasdock.sh` script and run one of the following commands to enter the GCTA container.

```bash
bash setup_gcta_gwasdock.sh
```
or 
```bash
./setup_gcta_gwasdock.sh
```
This clones the repository, builds the Docker image, launches a container with mounted input and output directories, and opens an interactive shell inside the container for GWAS analysis.


**Note:** Please modify the paths (`PROJECT_ROOT_DIR`, `LOCAL_INPUT_DIR`, `LOCAL_OUTPUT_DIR`) in the script to match your actual directory locations.

### Step 2: Run GWAS Analysis

Execute:
```bash
gcta64 --threads 4 --bfile ../input/827millet --pheno ../input/phenotype.txt --mlma --out ../output/GCTA_result
```
*(Ensure the input genotype and phenotype files are properly mounted and accessible.)*

This will generate the results file `GCTA_result.mlma` in the `output/` directory.

### Step 3: Get Top20 SNPs
To extract the top 20 SNPs with the smallest P-values, execute:
```bash
(head -n 1 ../output/GCTA_result.mlma && tail -n +2 ../output/GCTA_result.mlma | sort -k 9,9 -g | head -n 20) > ../output/GCTA_result_top20.txt
```
After running this command, `GCTA_result_top20.txt` will be available in the `output/`directory.

### Step 4: Review Results

Results are saved in the `output/` directory.

- `GCTA_result.mlma`: Contains all the GWAS analysis results.
- `GCTA_result_top20.txt`: Includes top 20 SNPs with the smallest P-values.

Please verify the output files to confirm the analysis completed successfully.


## Additional Notes

- Ensure that Docker is installed and running before proceeding.
- Confirm input files are correctly formatted.
  - The phenotype file should be in PLINK format: FID IID PhenoValue
  - The genotype file should be in PLINK binary format (.bed, .bim, .fam) 
  - Ensure that the .bed, .bim, and .fam files are in the same directory and have the same base name.
