# FaST-LMM GWAS Analysis Example

This folder contains scripts and instructions to perform GWAS analysis using FastLMM within a Docker environment, as part of the GWASDock toolkit.

## Contents

- `scripts/`  
  - `setup_fastlmm_gwasdock.sh` — Script to clone the repository, build the Docker image, and run the container.  
  
  - `run_fastlmm.py` — Python script to perform GWAS analysis inside the Docker container.

- `input/`  
  - This folder contains only the phenotype file `phenotype.txt`.  

  - Following the instructions in the main [README.md](../README.md) to download the phenotype file (`GSTP011.pheno`). Convert it to the FaST-LMM-compatible format using:  

    ```bash
    (echo -e "FID\tIID\tTSLL"; awk 'BEGIN{OFS="\t"} NR>1{print $1, $1, $2}' GSTP011.pheno) > phenotype.txt
    ```
  - **Note:** The genotype files are not included in this repository. Download these files as instructed in the main [README.md](../README.md).
- `output/`  
  - The directory stores the results of FaST-LMM GWAS analysis, generated by `run_fastlmm.py`.
## Usage

### Step 1: Set Up Environment and Start Container

```bash
bash setup_fastlmm_gwasdock.sh
```
or 
```bash
./setup_fastlmm_gwasdock.sh
```
This clones the repository, builds the Docker image, launches a container with mounted input and output directories, and opens an interactive shell inside the container for GWAS analysis.


**Note:** Please modify the paths (`PROJECT_ROOT_DIR`, `LOCAL_INPUT_DIR`, `LOCAL_OUTPUT_DIR`) in the script to match your actual directory locations.

### Step 2: Activate Python Virtual Environment

Inside the container, run:

```bash
source fastlmm-venv/bin/activate
```

### Step 3: Run GWAS Analysis

Execute:

```bash
python ./input/run_fastlmm_gwas.py
```

*(Ensure the input genotype and phenotype files are properly mounted and accessible.)*

### Step 4: Review Results

Results are saved in the `output/` directory.

- `Fastlmm_result.csv`: Contains all the GWAS analysis results.
- `Fastlmm_result_top20.csv`: Includes top 20 SNPs with the smallest P-values.

Please verify the output files to confirm the analysis completed successfully.


## Additional Notes

- Ensure that Docker is installed and running before proceeding.
- Confirm input files are correctly formatted.

- **Permission denied** error when running the script:

  If you see:  
  ```bash
  permission denied: ./setup_fastlmm_gwasdock.sh
  ```  
  Run the following command to grant execute permission:

  ```bash
  chmod +x setup_fastlmm_gwasdock.sh
  ```

- **Missing developer tools** error     
  ```bash
  xcode-select: note: No developer tools were found, requesting install
  ```

  This indicates that Xcode Command Line Tools are not installed. These are required for many development tasks, such as cloning repositories with git.

  You can start the installation by running:

  ```bash
  xcode-select --install
  ```

  Follow the prompts to complete the installation. Once installed, try running the script again.
